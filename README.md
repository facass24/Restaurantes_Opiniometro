# Opiniometro de restaurantes

Clasificacion de sentimiento (positivo / negativo) de resenas de restaurantes
en espanol, con Naive Bayes y Regresion Logistica.

Proyecto integrador de Topicos y Programacion Avanzada.

## Requisitos

- Python 3.12

## Estructura

- `src/nlp/`: pipeline de preprocesamiento de texto
- `src/models/`: entrenamiento y evaluacion de los modelos
- `api/`: backend (FastAPI)
- `frontend/`: interfaz web
- `data/`: datos crudos y procesados
- `notebooks/`: analisis exploratorio y experimentos
- `artifacts/`: modelo y metricas generados por el entrenamiento
- `tests/`: pruebas automatizadas
- `docs/`: informe tecnico
- `params.yaml`: parametros del experimento
